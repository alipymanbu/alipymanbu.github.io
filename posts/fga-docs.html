用了三年 FGA 才发现的五个隐藏玩法

软件下载 2026-10-16 ·约 7 分钟 ·老杨

助战匹配精度调对等于多了半个打手、Preview Build 自动升追加技能、战斗间隙自己跑强化——这些藏得真深

你以为 FGA 只是个点点点的战斗脚本？其实去fga官网转一圈会发现它还藏着一整套让日常体验上一个台阶的冷门设置，官方文档分散在好几个角落，翻完才发现以前白白手动点了好几百小时。

藏在支持目录里的助战匹配黑科技

FGA 刚装好时助战选择是个很鸡肋的东西——默认图片只能认热门从者，冷门一点直接识别不到，很多人索性关掉助战选择手动点。但你知道吗，助战系统的核心入口根本不是 FGA 应用里的那些开关，而是存储目录下的 support/ 文件夹。

这个文件夹里放什么、怎么放，直接决定了助战匹配能有多精细。FGA 匹配用的是图像相似度阈值，默认 80%，但你可以把阈值调到 90% 让误识别几乎消失，也可以降到 70% 让同一张脸不同破图都能被认出来。支持图片可以按从者名分子目录，比如 Merlin/asc1.png、asc2.png……把每个破图的头像都截一遍，梅林不管是初影还是满破都能精准匹配到。

更狠的是好友名截图匹配——你可以截一个好友的名字文字区域放进去，FGA 会优先选这个好友挂的从者。我有个朋友专门挂满破万华镜孔明，把他名字截完扔进去之后，助战界面刷五次能命中四次。还有个 MLB（礼装满破）单独检测阈值，默认 ~70%，如果你发现 FGA 老把没满破的礼装当满破，可以把这个阈值往上调两三个点。

这些参数全在设置里藏着——"相似度阈值""MLB 相似度阈值"——大部分人装完 FGA 就再也没翻过这些调微调项。

Preview Build 才有的增强强化包

很多人不知道 FGA 有两个版本：标准版和 Preview Build。标准版能自动喂狗粮、自动升技能，但 Preview Build 多出来一堆强化相关功能，官方没怎么宣传，功能列表上也没明显标注。

Preview Build 能自动升追加技能——这东西手动点起来极其折磨，需要的材料五花八门，QP 消耗也大。还有自动升礼装和礼装 EXP 炸弹批量升级，后者能把多余的礼装 EXP 一次性喂给目标礼装，比手动一张一张点效率高太多。最值钱的是自动卖满级礼装，多出来的满破礼装直接卖换 QP，活动结束后整理库存能省十几分钟。

怎么判断自己用的是哪个版本？FGA 设置里有个"关于"页面，Preview Build 会在版本号后面带个 -preview 后缀。如果没有，去fga下载换个渠道，Preview Build 一般在 GitHub Releases 里单独放。

战斗间隙自动跑强化，不需要你手动触发

这是我最近才发现的一个开关——FGA 的战斗循环能自动穿插从者强化环节，触发条件是检测到某个战斗队伍里的从者 EXP 槽快满了，或者技能没满级。

它的工作流是这样的：战斗循环跑着跑着，FGA 发现阿拉什的经验条快满了，自动暂停战斗、退出到关卡菜单、进强化界面、喂狗粮、升技能（只升战斗配置里用到的那个技能）、再回到关卡菜单、继续跑战斗。整个过程完全不需要人盯着，AP 还没跑光，队伍里的从者已经被悄悄养了一圈。

配置入口在战斗配置里的"自动强化"相关选项，默认是关的。打开之后有几个参数要调：狗粮优先级（3 星先喂 / 2 星先喂 / 按效率喂，推荐按效率）、升技能优先级（战斗配置里用到的技能先）、QP 保留值（建议留 1000 万以上防止 QP 花光导致强化中断）。

唯一的限制是自动强化和战斗脚本不能同时跑——FGA 是单线程执行的，所以它的设计就是暂停战斗 → 强化 → 继续战斗，而不是并行。这个限制反而帮你省了额外操作，一次配置之后就不用管了。

悬浮按钮其实是可配置的遥控器

大多数人知道悬浮按钮在游戏左上角，但不知道它其实藏了一堆可配置项。首先是拖动记忆——长按悬浮按钮拖到屏幕边缘，重启服务后它会回到你上次放的位置，不会每次都跳回左上角。

然后是横屏限制。FGA 悬浮按钮默认只在横屏显示，这是因为 FGO 本身是横屏游戏，FGA 检测到游戏横屏才会显示。但如果你用的是可折叠设备比如 Surface Duo，竖屏也能显示——这是个特殊适配，很多人不知道。

还有个容易踩的坑：服务必须重启才能让新的悬浮窗权限生效。如果你在系统设置里开了悬浮窗权限，直接回到 FGO 是看不到按钮的——必须先在 FGA 主界面停服务、再启动服务，新权限才会被读取。这个细节在fga文档里提了一句但没加粗，我当初就是因为没重启服务白折腾了半小时。

厂商 ROM 的隐藏权限开关

MIUI、EMUI、ColorOS 这些定制 ROM 对悬浮窗的限制比原生 Android 严格得多，光开"显示在其他应用之上"还不够。

小米用户要额外开"后台弹出界面"——在权限管理页面的最底部，默认是关的。华为用户要同时开"显示在其他应用之上"和手机管家 → 悬浮窗管理里的 FGA 开关。OPPO 和 vivo 的设置路径差不多，都是应用管理里单独一项。

这些隐藏开关的坑在于：系统不会主动提示你缺了哪个权限，FGA 服务启动也不报任何错，就是悬浮按钮死活不出来。排查的时候容易误判成 FGA 的 bug，其实就是 ROM 多卡了一道。

最后

FGA 的功能密度比看上去大得多，很多"隐藏功能"只是因为设置路径深、文档分散而被忽略。助战阈值调对之后日常效率能翻倍，Preview Build 的强化包能把手动点的时间砍掉大半，厂商 ROM 的权限开关踩一次记住之后终身受益。

把 FGA 用透的感觉，就像给 FGO 开了个合法的外挂——不是作弊，是把重复劳动交给脚本，把时间留给游戏本身。顺便说一句，涉及的设置项和参数说明我也同步了 GitHub、Gitee、GitCode 三个仓库，想深入对照的可以翻翻看。上面这些技巧，总有一两个是你用了好几年也没注意到的。
