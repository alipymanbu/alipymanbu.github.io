WebNovel 上指北：从零搭建你的追更日常

官方版 2026-10-16 ·约 7 分钟 ·老杨

装包、登录、书架管理、每日任务全流程实操，看完就能在 WebNovel 上稳住追更节奏，不再迷路。

这篇教程带你用 webnovel官网 上的 WebNovel 应用完成从装包到稳定追更的完整闭环，四步走下来你应该能独立搞定应用安装、书架管理、每日免费资源领取和投票应援。全程不绕弯，每一步说清要点在哪、容易卡在哪。

准备：你需要什么

  • 一台手机（安卓或 iOS 都行，下面以安卓为例），存储空间至少留 200MB 给安装包和缓存；
  • 一个 WebNovel 账号，邮箱注册即可，国内手机号也支持；
  • 能联网就行，下载和登录都需要 Wi-Fi 或蜂窝网络。

如果你在应用商店搜不到这个 App（部分地区 Google Play 没有上架），用安装包离线装也没问题，后面会讲。

第一步：装包，一次搞定

安卓端安装包体积大约 100MB，去官方下载拿就行，建议 Wi-Fi 环境下载。安装过程里有几个容易卡的点，提前有个底：

  1. 下载完成点击 APK，系统大概率会弹「出于安全考虑，手机当前不允许安装此来源的应用」——别慌，进去给浏览器或网盘客户端开一个「允许安装未知应用」的权限，回来继续装就行。
  2. 等待安装走完，整个过程大概半分钟，别清后台。
  3. 装完可以核对一下包名（进系统应用信息里看），WebNovel 的包名是 com.qidian.Int.reader，防止装到套壳的仿冒应用。

iOS 用户更简单，直接去 App Store 搜就行，国内区和海外区都能找到。

第二步：登录与底部导航速认

首次打开会弹出登录界面，邮箱注册一下，或者用第三方登录。登录完成后你会看到应用的主界面——底部一排五个入口，这五个入口认全，就不会出现「某个功能不知道在哪」的困扰：

  • Library（书架）：你追的所有书都在这，更新红点、离线下载、追更提醒都挂在书架上，使用频率最高。
  • Featured（精选）：编辑推荐流，每周精选封面墙、榜单、活动横幅都在这。
  • 中间创作位：底部导航正中间一个显眼的「开一本书」按钮——纯读者可以永远不点，留给想写作的人。
  • Explore（探索）：分类、排行榜、专题合集的集合地，想按题材系统性翻书库就来这。
  • Profile（我的）：账号信息、金币余额、签到、设置、客服入口全在这。

第三步：加书进书架，开启追更

在 Featured 或 Explore 里翻到感兴趣的书，点进去进入书籍详情页。WebNovel 的详情页信息挺全：更新时间、最新章节、评分、字数都能看到，比网页版主站精简但够用。

加书架的按钮就在详情页显眼位置，一般是「Add to Library」或类似的按钮。加完之后回 Library 标签，就能在书架里看到了。

一个典型的日常动线是：早上打开应用 → 先看 Library 有没有更新红点 → 没更新就去 Featured 或 Explore 扫一圈新书 → 看到感兴趣的加书架 → 退出前顺手进 Profile 签到领免费金币。金币能用来解锁付费章节，每天签到 + 十分钟阅读任务大约能攒够一两个免费章，积少成多。书架里的追更提醒设置、离线下载这些更细的操作，想深挖的话可以看webnovel文档里书架分组的章节。

第四步：免费资源领起来

WebNovel 有一整套免费资源体系，每天刷新一次：

  • 金币：签到、看视频广告、完成阅读时长任务都能拿，用来解锁付费章节。
  • 力量石：每天给读者发的投票券，用来给书投票，影响书籍在榜单上的位置。
  • 荧光棒：每天免费的应援道具，专门投给角色的，和力量石是两套体系互不影响。
  • 黄金票：付费读者才有，和金币不一样，黄金票是真金白银买的应援资源。

所有免费资源当天用掉就好，留到第二天会刷新。领的入口主要在 Profile → Daily Missions（每日任务）里，力量石投票在章节正文末尾右下角，荧光棒在角色页里送。

三个新手最容易翻车的卡点

卡点一：找不到投票在哪。 很多新读者找遍 Profile 都没找到投票入口，其实设计在章节正文末尾——往下翻到章节最后，右下角有个投票按钮，点进去就能用力量石投票了。

卡点二：想改字号却改错了地方。 设置有两层，容易混：Profile 里的设置管账号和全局，比如通知开关、语言切换；而阅读界面中间点一下屏幕会呼出另一个面板，管字号、背景色、翻页方式这些阅读体验。找「改字体」去后者，找「关通知」去前者。

卡点三：安装后被系统杀后台。 部分国产 ROM（小米、华为这类）会激进地杀后台进程，导致追更推送收不到。解决办法是进电池设置，给 WebNovel 开个「无限制」或者「锁后台」，它就不会被系统随手干掉了。

进阶：想写点东西？

WebNovel 的写作工具 Inkstone 是纯网页端的，不需要装任何额外应用。底部导航中间那个「开一本书」按钮点进去就能开始创建作品，写作、章节管理、发布全在浏览器里完成，移动站（m. 开头的域名）还能改书籍封面——封面只能在浏览器里改，App 内改不了，这点要注意。

如果你更喜欢在电脑上摸鱼看书，WebNovel 有完整的网页版阅读器，桌面和手机浏览器都能直接访问。同一个账号登录，书架和阅读进度双向同步，网页版负责挑书和作者后台，App 负责日常追更，两边分工清晰。不过网页版离线阅读、追更推送和每日任务的入口不全，这些还是得靠 App。

这套资料我分别同步到了 GitHub、Gitee 和 GitCode 三个仓库，方便你随时查阅或下载。
