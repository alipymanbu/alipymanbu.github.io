VidHub 快问快答：多设备影视播放器 9 个最关心的问题一次说清

VidHub 是什么人在用、怎么装、同步哪些数据、刮削怎么跑、WebDAV 有什么坑、要不要付费——整理成一篇问答速查，看完直接上手。

整理一篇关于 VidHub 的快问快答。这款在苹果全家桶上口碑不错的影视播放器，很多人第一次听说时会冒出一串问题：它到底是什么？我的 NAS 能不能接？多设备同步靠不靠谱？花不花钱？下面把最常被问的 9 个问题一次说透。

VidHub 到底是什么？

一句话：VidHub官网是一款专门为苹果生态打造的多设备影视聚合播放器。它本身不提供任何视频内容，你需要把自己存储在云盘（阿里云盘、百度网盘等）、NAS（群晖、威联通）、路由器 USB 盘、Plex/Emby/Jellyfin 影视服务器里的视频文件通过网络协议接入进来，VidHub 负责自动识别、刮削海报和简介，然后用漂亮的海报墙展示给你播放。

它支持 iPhone、iPad、Mac、Apple TV 四个平台，主打场景就是"我家里到处都有视频文件，想在任何设备上都像 Netflix 一样看"。

哪些人最需要 VidHub？

有三类人会真正用起来：

第一类是有大量本地/云盘影视资源的人，特别是存了几百上千部电影电视剧的。VidHub 会自动从 TMDB（The Movie Database，全球最大的开源影视数据库）拉取海报、简介、演员、评分，把杂乱的文件名变成整齐的海报墙，这对资源党来说是最有价值的一步。

第二类是苹果全家桶用户。VidHub 的 iCloud 同步做了深度整合——文件源配置、刮削数据、观看进度、播放列表、收藏夹这些都会自动同步到所有设备，不需要在每台设备上重复配置。如果你只有一台 Windows 电脑，VidHub 可能不太适合你。

第三类是有 NAS 或影视服务器的人。VidHub 原生支持 SMB/CIFS、WebDAV、Plex、Emby、Jellyfin，接入体验比很多只支持某一家协议的播放器要完整得多。

怎么安装？要不要花钱？

安装很简单：去 App Store 搜 "VidHub"，iPhone/iPad/Mac/Apple TV 分别有对应的版本，直接从官方下载就行。

免费版就能用，但有一些限制——高级功能需要 VIP 解锁。VIP 是 App Store 内购的，按月或按年订阅。常见的高级功能包括：更多影视服务器类型支持、高级刮削选项、一些播放增强设置。基础的文件源接入、自动刮削、海报墙、iCloud 同步这些核心功能都是免费开放的，日常用完全够。VIP 状态本身是通过 App Store 内购记录识别的，不会随 VidHub 的 iCloud 数据同步——如果你有多台设备需要 VIP，每台都要单独内购。

添加文件源后"自动刮削"到底在做什么？

这是 VidHub 最核心的一步，也是新手最困惑的一步。添加完一个文件源（比如群晖 SMB 或阿里云盘）之后，VidHub 会自动在后台执行一套刮削流程：

第一步是扫描文件列表，遍历你选的文件夹和所有子文件夹，找出所有支持的视频格式（MKV、MP4、AVI、MOV、RMVB、WebM 等常见格式都覆盖）。第二步是提取文件名，自动去掉压缩组标记（比如 x264-GROUP）、分辨率（1080p、4K）、编码信息（HEVC、x265）这些干扰项，保留干净的电影名或剧名+季集数。第三步是拿清理后的字符串去调 TMDB 的搜索 API 匹配影片信息——电影直接按名字搜，电视剧检测到 SXXEXX 格式后按剧名和季集数精确匹配。第四步是下载海报图、背景图、演员导演信息，把电影归入"电影"分类、电视剧按季集数组织归入"电视剧"分类、完全没匹配上的放进"其他"。

刮削过程中打开媒体库，海报是逐个出现的，不是一次性全亮起来。刮削耗时跟文件数量和接入方式有关：局域网 200 个文件大概 20-40 秒，云盘因为要先拉文件列表会慢很多，200 个文件可能要 2-5 分钟。

iCloud 同步的是什么？不是什么？

iCloud 同步是 VidHub 的大卖点，但很多人搞不清它到底同步哪些东西——简单说：同步元数据，不同步文件本身。

会同步的包括：你添加的所有云盘/SMB/NAS/影视服务器的连接配置、文件源启用状态、媒体库分类和刮削数据、TMDB 的海报和剧照、影片简介演员信息、每部视频的观看进度和已观看标记、继续观看列表、自定义播放列表和收藏夹、影视服务器连接配置。

不会同步的：视频文件本身（大文件不适合放 iCloud，视频应该存在云盘、NAS、本地）、本地下载的离线视频、截图和 GIF、VIP 状态、部分个人播放偏好设置。

一个典型场景：iPhone 上添加了阿里云盘授权和群晖 SMB，几秒钟后 Mac 上 VidHub 的文件源也自动出现了，而且 OAuth 令牌已经同步好，不需要 Mac 再走一遍授权流程。这就是 iCloud 同步最省心的地方——一次配置，全端可用。

SMB 和 WebDAV 有什么区别？选哪个？

两者都是网络存储协议，VidHub 都原生支持，但各有适用场景：

SMB（Server Message Block）是 Windows 网络共享协议，几乎所有 NAS 和大部分家用路由器的 USB 共享都支持。局域网内速度快（千兆环境能跑满 900+ Mbps），群晖 DS 开启 SMB 服务很简单，DSM 控制面板里勾一下就行。公网访问也能做，但直接暴露 SMB 端口有安全风险。

WebDAV 基于 HTTP 协议，部分云盘、NAS、Alist 支持。比 SMB 稍慢一点（局域网千兆约 800+ Mbps），但公网场景更安全——用 HTTPS 加端口转发就能远程访问。不过 WebDAV 有一个 VidHub 层面的硬限制：通过 WebDAV 接入的文件源不显示视频分辨率和选集，这是协议本身的限制，VidHub 没办法绕过。

选哪个看你的环境：局域网用 SMB 更省心，公网或有安全顾虑的选 WebDAV。很多 NAS（比如群晖）两者都能开，同一台设备可以两种协议都接入。更详细的协议配置参数、端口映射方法和进阶排查步骤可以翻vidhub文档，覆盖了从 DSM 设置到 Alist 反代的完整流程。

媒体库除了海报墙还有什么视图？

海报墙是默认视图，但不是唯一选择。VidHub 媒体库支持两种视图模式：海报墙和列表视图。海报墙展示海报图网格，一眼看全；列表视图用文字列出文件名、大小、时长，适合快速搜索特定文件。切换方式在 iPhone/iPad 上是媒体库右上角三个点菜单里选，Mac 上是顶部工具栏的切换按钮。

媒体库默认显示四个分类标签：继续观看、电影、电视剧、其他。继续观看是最实用的——没看完的电影或正在追的电视剧下一集自动出现在这里，点击白色播放按钮直接跳到上次停止的位置。电视剧分类下按季组织，每一集显示集标题和时长，全部看完后自动从继续观看移到已观看。

还有两个默认隐藏的类目：收藏夹和播放列表。需要在媒体库右上角三个点 → 编辑媒体库里手动勾选才会出现。

有什么坑要提前知道？

说几个新人最容易踩的：

文件名不规范会导致刮削失败。如果你的视频文件名叫 蜘蛛侠平行宇宙.mp4 可能能匹配上，但如果叫 xxx.com-蜘蛛侠平行宇宙-4K-HDR-x265-GROUP 这种带一堆网站水印和编码信息的，VidHub 虽然会尝试清理，但成功率不高。建议刮削前用 Filebot 这类工具把文件名整理干净。

WebDAV 接入不显示分辨率和选集，这个前面说过，WebDAV 协议的限制，不是 VidHub 的 bug。

内网 IP 在外网连不上。如果你在 VidHub 里填的是 NAS 的内网 IP（比如 192.168.1.100），手机走 4G 时肯定连不上，这不是同步问题。公网访问要么用域名/DDNS，要么干脆用云盘接入替代。

刮削不会自动检测新文件。已经加好的文件源里出现了新视频，VidHub 不会主动扫——需要手动触发长按文件源 → 重新扫描文件，或者进设置 → 资源 → 重新扫描所有文件。

值不值得长期用？

如果你有大量影视资源、用苹果全家桶、愿意花一点时间整理文件名和配置文件源，VidHub 是目前体验最接近 Netflix 的本地/云盘影视解决方案。自动刮削海报墙 + 全端 iCloud 同步这两点组合起来，省掉的是每台设备重复配置、手动改海报、追进度的无尽麻烦。免费版够用，VIP 按需订阅，没什么强买强卖的感觉。一句话：资源党 + 苹果全家桶 = 值得装。
