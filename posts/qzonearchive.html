QzoneArchive 上手实战——把十年 QQ 空间一次存进本地

正版 2026-10-16 ·约 6 分钟 ·老杨

从下载安装到扫码登录、启动归档、导出本地备份，手把手走完 QzoneArchive 的完整流程，顺手解决 macOS 安全拦截、归档期间切号冻结等新手必踩的坑。

这篇教程结束时，你会把自己 QQ 空间里从第一条动态到最近一条的全部内容——包括图文、评论、点赞、相册、互动关系——完整拉到本地，做成一份属于自己的只读归档。

准备：先把安装包拿对

动手之前先确认三件事：你的操作系统、芯片架构（Mac 用户）、以及只从官方渠道拿包。

QzoneArchive 是 Tauri 写的桌面应用，它的官网上有完整的功能说明和更新日志，Windows、macOS、Linux 三端都有现成安装包。Linux 这边分 deb、rpm、AppImage 三种格式——不确定就挑 AppImage，绿色免安装，双击就能跑。macOS 用户要多注意一步：Apple Silicon（M1/M2/M3/M4）和 Intel Mac 用的是不同的 dmg，前者找文件名带 aarch64 或 arm64 的，后者找 x86_64。查看芯片类型的路径是左上角苹果菜单 → 关于本机 → 看"芯片"一栏。

安装包从官方下载或仓库 Releases 页面拿。市场上已经出现过冒充这个项目的恶意版本，套个同样的图标，扫码后把 Cookie 上传到未知服务器。下载完最好核对一下 README 里给的 SHA256 哈希，Windows PowerShell 一行 Get-FileHash -Algorithm SHA256 <文件名> 就能算，对不上的直接删。

安装本身没什么悬念。Windows 双击安装包一路下一步，macOS 把 dmg 里的图标拖进 Applications 文件夹，Linux 的 deb 用 sudo apt install、rpm 用 sudo rpm -i、AppImage 先 chmod +x 再直接运行就行。

第一步：扫码登录，别急着切号

启动应用后第一个页面就是登录。有两种方式：二维码扫码，或者内嵌 WebView 窗口手动登录。

推荐用扫码——手机 QQ 右上角加号扫一下，电脑端自动跳转。两种方式本质上都是让 QzoneArchive 拿到你的 QQ 空间接口访问凭证（Cookie），这个凭证始终存在 Rust 后端内存里，前端 Vue 组件碰不到，也不会写到磁盘上。

归档没跑完之前，别在手机 QQ 或电脑 QQ 上切账号。 项目 README 里专门写了这条注意事项。推测原因是 QQ 空间接口检测到同一个账号从两个不同客户端、不同 IP 同时访问，会触发风控临时冻结。如果确实要用另一个账号，换一台设备操作。

第二步：启动归档，让它自己跑

登录成功后进入主界面，点一下"开始归档"按钮，剩下的事交给它。

归档过程是分批次拉取的——先走动态列表、逐条抓正文和配图，再扫相册和互动数据。界面上会实时显示当前进度、剩余条数、以及一个限流倒计时。别小看那个倒计时，QQ 空间接口有频率限制，拉太快会被临时封，QzoneArchive 已经内置了限流逻辑，慢一点稳一点。

归档跑着的时候你该干嘛干嘛，它是后台任务，关了窗口会暂停，再打开能从断点续跑。如果网络断了，重连后自动继续，不会从头来。

归档完成后数据默认存在应用自己的 SQLite 数据库里，每条动态带完整的正文、配图路径、评论列表、点赞数和时间戳。媒体文件（图片、视频）会被下载到本地一个独立目录，和数据库一起组成完整的归档副本。

第三步：导出成你想要的格式

归档跑完别急着关——QzoneArchive 的价值不止于存一份数据库，它能把归档内容导出成多种格式，方便长期留存和迁移。

导出页面让你选范围（全量还是某一年、某几个月）和输出目录。QzoneArchive文档里提到的导出格式包括 HTML 快照、纯文本、以及结构化的 JSON。HTML 快照是最省心的选择——双击就能在浏览器里看，样式和原空间接近，配图、评论、互动都能完整展示，哪怕哪天 QQ 空间服务下线了，这份快照照样能翻。

新手必踩的三个坑

macOS 首次启动的 Gatekeeper 拦截。 从 Applications 里双击打开时 macOS 会弹"无法打开，因为无法验证开发者"。这是正常行为，不是程序有病毒。解决方法：在 Applications 里找到 QzoneArchive，右键 → 打开，弹出的对话框再点一次"打开"就行。或者去系统设置 → 隐私与安全性，滑到底部点"仍要打开"。

AppImage 提示 libfuse.so.2 缺失。 Ubuntu 24.04+ 常见，因为新版默认没装 FUSE2。两种解法：要么 sudo apt install libfuse2 装回来，要么用 ./QzoneArchive-*.AppImage --appimage-extract-and-run 跳过 FUSE 直接解压运行。

归档跑一半被风控暂停。 别慌，QzoneArchive 会自动退避等待，等限流窗口过了继续拉。如果反复触发，去设置里把请求间隔调大一点，或者暂停一段时间再开。

往下还能玩什么

归档完成只是起点。你可以用导出的 HTML 快照搭个本地静态站给自己看，也可以把 JSON 喂给自己写的小脚本做数据挖掘——比如统计哪年发得最多、哪些朋友互动最频繁、配图里什么关键词出现得最多。互动排行榜页面已经帮你算好了一份，进去看一眼说不定能发现一些自己忘了的旧时光。

代码和安装包同步维护在三个仓库上——海外的 GitHub、国内访问更快的 Gitee，以及社区备份 GitCode，挑哪个顺手用哪个。
