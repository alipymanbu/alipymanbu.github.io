Anytype 到底值不值得掏钱？四档定价掰碎了算

官网版 2026-10-16 ·约 9 分钟 ·老杨

从免费版到 Ultra 每月 16 刀，Anytype 每一档多给了什么、对哪类人真有用。把账算明白再决定付不付。

它到底值不值得掏钱？

这是我盯着从Anytype官网下载的桌面端左上方那个 Upgrade 按钮问了自己至少十遍的问题。界面角落里永远有一行小字在提醒你——你现在用的是免费版，还有 3 个共享 Channel 的额度，远程存储 1GB 封顶。每次我在协作里要加第四个小组的时候、每次导出备份发现压缩后还剩两百多兆的时候，那个按钮就闪一下。

所以今天把这笔账算清楚。四档定价、各自的权益边界、什么情况下免费版真的够用、什么情况下升级是刚需——逐条拆。

定价拆解：四档到底差在哪

先把数字摆出来。官方下载到手就能看到完整的定价面板，价格在同类产品里算克制，最便宜的 Plus 只要 $4/月，最贵的 Ultra $16/月，年付通常有折扣。对比一下 Notion Business $15/用户/月的单价，Anytype 的天花板还不到别人的起步价。

但价格低不代表每一档都划算。关键是每一档多给了什么，以及那东西对你有没有用。

免费版给你了完整的功能，只在三个地方卡你：

远程加密存储 1GB——注意这是加密压缩后的大小，不是原始文件体积，翻一下Anytype文档就能看到完整的存储计量说明。纯文字笔记一条才几 KB，1GB 能装几万条；加图片也够日常用。本地存储完全不受限，你爱存多少存多少，只是多设备同步的时候走的是远程那条路。

共享 Channel 限 3 个——这是真正的紧箍咒。Personal Channel（自己私人用的空间）不限，但和别人协作的共享空间只能有三个。同时在三个以上的小组里跑，或者跨多个项目协作，这个额度很快就顶满。

ANY ID 必须 9 字符以上，而且不能自定义——ANY ID 是你在 Anytype Network 上的公开标识，类似用户名，用于 Web Publishing 和别人搜索邀请。免费版是系统随机分配的长 ID，比如 alpha-beta-gamma-delta 这种，没法改成自己想要的名字。

Plus 档 $4/月： 共享 Channel 从 3 个变无限，远程存储扩容，ANY ID 可以自定义但还是 9+ 字符。这一档的核心价值是无限协作空间——如果你有 4 个以上的协作小组，$4 花得很值；如果只有一两个，这档就显得多余。

Pro 档 $8/月： 远程存储继续扩容，ANY ID 缩短到 7+ 字符。这一档比较微妙——对于个人用户来说，7 字符和 9 字符的 ID 差别不大；对于小团队来说，更多的远程存储可能是硬需求。Pro 档比较像是给"重度个人用户 + 两三个人的小团队"准备的。

Ultra 档 $16/月： 远程存储拉满，ANY ID 可以是 5+ 字符（短 ID），还有一些高级特性。这一档是给高级用户和团队核心的——如果你要做 Web Publishing 而且想要一个好看的短 ID，或者团队里有人需要大容量远程同步，这档才体现价值。

还有一个额外信息值得记一下：Anytype 背后不是商业公司，是荷兰海牙的 Anytype Foundation，非营利基金会。这意味着会员费是用来支撑服务器成本和全职开发者工资的，没有 VC 退出压力，也不太可能哪天突然"变现"搞涨价或者砍功能。这点在决策里是加分项——你不是在给一家要融资的创业公司送钱，是在给一个承诺开源协议的基金会交服务器费。

分人算账：你的使用强度对应哪一档

定价拆完了，现在得对号入座。同样 $4/月，对轻度用户是浪费，对重度用户是刚需。我按使用强度分三类人算这笔账。

轻度用户：免费版完全够，一分钱不用花。

判断标准：笔记以文字为主，图片很少；同时协作的小组不超过 3 个；远程同步只是偶尔开一下，主要在本地写东西。

对这类用户来说，免费版的 1GB 远程存储其实很宽松——纯文字笔记压缩后体积极小，哪怕写上万条也用不完。3 个共享 Channel 对绝大多数个人学习者和独立开发者来说已经覆盖了：一个给项目协作、一个给朋友技术交流、一个给家人共享清单。够用了。

真到了需要第四个共享 Channel 的时候再升级也不迟，而且 Plus 档 $4/月的门槛很低，随时可以切。

主力用户：Plus $4/月是性价比最高的选择。

判断标准：同时在 4 个以上的协作空间里工作；笔记里有不少图片（截图、手绘、PDF 扫描）；每天多设备同步频率高；对 ANY ID 有个性化需求（比如想做 Web Publishing，需要一个好记的 ID）。

Plus 档的 $4/月折合人民币大概 30 块，一杯咖啡的钱。换来的是无限共享 Channel + 更大的远程存储 + 自定义 ANY ID。这里的核心价值是"无限共享 Channel"——如果你真的因为第 4 个协作空间而被卡住过，就知道这个限制有多烦。远程存储的扩容是附带的福利，自定义 ID 是锦上添花。

主力用户其实不太需要 Pro 和 Ultra——除非你的远程存储需求特别大（比如笔记里堆了大量视频），或者团队里已经有几个人在用 Anytype 协作，那时候 Pro 档更多的存储配额才开始有意义。

重度用户 / 小团队：Pro 或 Ultra 按需选。

判断标准：团队人数 3~10 人；远程存储压力大（多人协作上传的图片、文档体量可观）；有公开 Web Publishing 需求且想要短 ID；或者已经是基金会的支持者，想多贡献点服务器费用。

Pro $8/月和 Ultra $16/月之间的选择比较简单——你如果真的需要 5 字符的短 ANY ID（比如要做一个短 URL 的发布页面），直接上 Ultra；否则 Pro 档的存储扩容已经够用了。小团队的话，可以考虑 Business 企业版——不过那个定价文档里没细写，得去官网查。

从时间账来看，主力用户花 $4/月节省的"因为共享 Channel 不够而被迫在不同工具之间切换、手动同步"的时间，远超过 30 块钱。重度用户花 $8/月节省的协作摩擦成本，对小团队来说也不是小数。

替代方案：不付这笔钱的代价

有人可能会说：Notion 免费版也够我用，为啥还要给 Anytype 掏钱？这是个好问题。

Notion 免费版的限制是 5MB 单文件上传、无限协作人但上限 10 人、没有高级视图。对比 Anytype 免费版 1GB 远程存储和 3 个共享 Channel，两者的限制点不一样——Notion 卡单文件大小，Anytype 卡共享空间数量。如果你不怎么传大文件、协作小组也不多，Notion 免费版其实是更强的选择。

另一个替代思路：不用共享 Channel，改用其他工具协作，Anytype 只做个人知识管理。比如协作走飞书文档或 Notion，个人笔记留在 Anytype。这样免费版的 3 个共享 Channel 可能根本用不上——一个留空、一个给自己的小项目、一个留着备用，刚好。代价是跨工具的数据一致性要自己维护，但对于不重度依赖 Anytype 协作的人来说，这条路完全走得通。

还有一个选项：等一等。Anytype 基金会会不会调整定价？Plus 档会不会降价或者免费版的共享 Channel 上限会不会放宽？说实话基金会没有 VC 压力，定价调整的自由度比商业公司大，但也没有动力主动降价。不过 3 个共享 Channel 的限制如果后续在社区里被大量吐槽，基金会可能会考虑——这类非营利组织对社区声音的反应通常比 VC 驱动的公司更快。

结论：三秒对号入座

把账算到底，结论其实很简单：

  • 轻度用户 → 免费版死守，一分钱不用花，等真正被卡住了再说。
  • 主力用户 → 闭眼 Plus $4/月，这是四档里性价比最高的选择，$4 换无限协作空间和更大的远程存储，值。
  • 重度用户 / 小团队 → Pro 或 Ultra 按需选，看你是更需要存储还是更需要短 ID。

特别提一句那个 ANY ID 的事——如果你还没决定要不要升级，但又对那个随机长 ID 耿耿于怀，忍忍就好。自定义 ID 确实好看，但 9 字符的长 ID 也能用，Web Publishing 的 URL 长一点不影响别人访问。这不是刚需，是锦上添花。

最后说说 Anytype 作为非营利基金会这点。我个人偏向把这算作决策里的正面因素——基金会模式意味着它不会哪天突然给所有免费用户强制降配、也不会突然把核心功能锁到付费墙后面。你付费买的是稳定，而不是被 VC 追着增长的焦虑。这套定价信息我也整理了一份，在GitHub、Gitee、GitCode三个仓库都存了备份，方便哪天 Anytype Foundation 调整定价时回来对照。30 块钱一个月换这种确定性，对主力用户来说其实挺划算的。
