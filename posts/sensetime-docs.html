商汤日日新里藏得最深的四个玩法：复刻直播间、图片变视频、Skill 自由组合……

手机版 2026-10-16 ·约 8 分钟 ·老杨

大多数人只知道商汤是做安防摄像头的，不知道日日新 SenseNova 生态里藏着复刻直播间、一张图生成数字人视频、Token Plan 内置工作流引擎等四个冷门但杀招级的功能。

引子：你以为它只是个摄像头厂？

坦白说，在翻透它之前我对商汤的印象和大部分人一样——就是做手机人脸识别、安防摄像头那种 AI 硬件公司。打开日日新 SenseNova 的sensetime官网和文档站，起初也只是想找个 API、顺便看看官方下载有没有什么能本地跑的 Demo，结果一头扎进去三个月，发现整个生态里藏着一批官方几乎不宣传、但对中小团队来说是杀招的功能。

下面这四个，每一个都让我觉得"用了这么久居然没发现"。

一、Token Plan 不是便宜 API，是 Skill 自由组合的长链路引擎

Token Plan 刚上线的时候我第一眼扫过去："哦，按量计费省 60%，Free 档 0 元/月"——这不就是另一个按 token 计费的 API 套餐吗？

结果翻到sensetime文档里一段没加粗的小字才发现，这东西藏得比我想的深多了。Token Plan 根本不是个单纯的计费方式，它是一个办公生产力能力包——里面捆绑了 8 项 Cowork-Skills 组件，贯穿理解、执行、生成三层，可以独立调用解决单点任务，也能自由组合跑通长链路。

这意味着什么？假设你是一个电商运营，以前可能要自己写脚本调不同模型：用一个模型抓评论数据、另一个做情感分析、第三个生成回复话术、第四个排定时推送。现在 Token Plan 里直接就能把这些 Skill 串成一条流水线，一次跑到结果。商汤自己的官方说法是"复杂办公流程一次跑到结果"，但没说的是——这个组合能力跟 token 计费是分开的，你只要在 Token Plan 的用量额度内，用 Skill 串多少次都不额外收费。

什么人用得上？有固定办公流程、不想自己搭 Agent 编排框架的中小团队。什么人可以无视？只调单次模型推理、不涉及复杂工作流的开发者。

二、复刻直播间：一段往期视频克隆一整间直播间

这个功能藏得真深，甚至在文档站里都不是一个独立章节——它混在如影数字人的「超级直播间」子产品里，埋在一堆功能点中间。

你猜怎么开？打开如影数字人控制台，进超级直播间，找「复刻直播间」按钮。就这么简单。但它做的事情远不止"数字人替身"那么简单：

不需要真人模特、不需要绿幕棚、不需要提词器——只喂一段你店铺往期直播的视频，它就能生成一个 7×24 小时在线的数字人主播，连主播的说话节奏、停顿习惯、甚至跟观众互动时的语气都能复刻出来。

但这还不是最狠的。它还有个「多模态大模型智能运营」功能：按商品交易额、互动频次等维度自动选品，把一个长直播里最能卖的品自动拆成多段短视频，特写镜头智能提取。商汤自己测的是直播运营效率提升 7 倍。

我第一次看到这个功能的时候反应是："这不就是把之前一个运营团队的活儿，交给一个模型干了？" 而且不需要你有任何拍摄剪辑经验，不需要绿幕棚，不需要真人出镜——你只要有一段过去的直播录像。

什么人用得上？电商卖家、本地生活商家、想做带货但没有直播间资源的个人。什么人可以无视？只做纯内容短视频、不涉及实时互动的创作者。

三、图片数字人：一张图 + 一段音频 = 3 分钟以上视频

如影数字人还有一个子产品叫「图片数字人」，名字听起来平平无奇，但能力完全是反常识的。

你猜做一条数字人视频需要什么素材？大多数人的第一反应是：真人拍摄、动作捕捉、至少得有一段真人出镜的视频吧？

错。如影图片数字人只需要一张图片 + 一段音频。

没错，就是你手机相册里随便一张人脸照片，加上一段你自己录的音频——就能生成一条高质量、多语种的数字人视频。而且还不是那种嘴型对不上的粗糙版本，官方宣称是 Rap 级口型对齐——连快速说唱的咬字都能跟得上。更离谱的是，它支持 Prompt 驱动动作：你可以说"让它举起右手"或者"让它做一个惊讶的表情"，还能指定多人互动的场景。

输出时长也不短——单条可以做到 3 分钟以上，支持说话、唱歌等多种场景。对于做知识科普短视频、教育培训内容的人来说，这等于把"出镜"这件事的门槛降到了零。

什么人用得上？知识博主、教育培训从业者、不想露脸但需要真人形象出镜的内容创作者。什么人可以无视？追求极致真实感、需要精细表情表演的影视级创作者。

四、SSP 训推一体：不用换平台的分布式训练

这个功能藏在 SenseCore 算力池的技术细节里，对于做 AI 应用的开发者来说可能是最被低估的一个。

SSP（SenseScale AI Compute Platform）是商汤面向企业的训推一体平台。听起来没什么特别的，但商汤自己没怎么宣传的两个技术细节值得注意：

第一，从交互式开发调试到大规模分布式训练再到高效推理，全在一个平台上完成。你不需要在 PyTorch MPI 集群、Jupyter Notebook 开发环境、推理服务之间来回切换——一个 SSP 搞定。对于还在不同平台之间搬数据的团队来说，这省的不只是时间，还有数据迁移的风险。

第二，CKPT 读写速度提升 10 倍——通过多级缓存机制实现的。做过大模型训练的人都知道，checkpoint 保存和加载是训练效率的瓶颈之一，特别是在 10,000 卡规模的并行训练里。商汤说 SSP 支持高达 96% 的线性加速比，这里面 CKPT 的提速功不可没。

什么人用得上？科研机构、正在做大模型应用落地的互联网团队、具身智能赛道的创新实践团队。什么人可以无视？只调 API 不训模型的应用开发者、小规模微调就能搞定的项目。

坑别踩：三个容易忽略的限制

藏得深的功能往往也藏着限制，这三个我试过踩过：

Token Plan Free 档有隐形配额——每个模型每 5 小时 1,500 次调用，特殊模型不在这个范围内。看起来 0 元很香，但如果你要做连续高频调用（比如跑一个 24 小时的自动化运营任务），5 小时窗口的配额可能不够用。而且 Lite / Pro 档到现在还没上线，想升级也升不了。

复刻直播间依赖往期素材质量——如果你的往期直播是用手机竖屏录的、光线差、背景杂乱，复刻出来的数字人质量会打折扣。最好用绿幕棚或者光线均匀的横屏直播录像作为复刻源。

图片数字人的私有化部署需要商务对接——虽然它支持 API 调用和私有化部署，但私有化部署不是自助开通的，得跟商汤的商务团队谈。如果你的数据不能出域，这个门槛要提前考虑。

收尾

这四个功能里，让我重新理解一件事：很多时候不是软件没能力，是官方没把它说清楚。日日新 SenseNova 生态里藏的东西远不止这四个——算力池的异构混训、数字人的 API 接口、甚至算力节点的全国布局——每深挖一个都能发现新东西。

把它用透，比换一个新工具更值。

想直接拿完整资料的话，我在GitHub、Gitee、GitCode三个仓库都维护了一份备份，哪个方便用哪个。
