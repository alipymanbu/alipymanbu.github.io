Twire 是什么？安卓 Twitch 第三方客户端快问快答

中文版 2026-10-16 ·约 6 分钟 ·老杨

整理了 7 个关于 Twire 的高频问题：它到底是什么、该不该装、怎么装、核心功能有哪些、有哪些使用限制，一篇速查。

整理一篇关于 Twire 的快问快答——这是一款在 F-Droid 上开源的 Twitch 第三方安卓客户端，很多人第一次听说时都会有类似的疑问。下面按问答形式逐一解答。

Twire 是什么？和官方 Twitch 客户端有什么区别？

一句话：Twire 是 Twitch 的开源第三方客户端，主打无广告和干净的界面。它的官网上写清楚了三条设计原则——无追踪、无广告、完全开源。它通过 Twitch 公共 API 获取数据，界面呈现是自己实现的，和官方客户端走的是两条路线。核心差异有三个：完全无广告（包括推荐流之间的插屏广告）、开源可审计（代码托管在 GitLab，任何人可以查）、界面简洁信息密度更高。频道卡片同屏能展示更多条目，不需要在一堆广告里找想看的内容。

谁适合用 Twire？

三类用户：第一，经常看 Twitch 但不想被广告打断的人——官方客户端的插屏广告频率不低，Twire 是零广告体验；第二，重视隐私和开源的用户——F-Droid 认证意味着它没有追踪器、没有闭源组件；第三，平板或大屏设备用户——Twire 支持侧边抽屉式导航，官方客户端只有底部标签，大屏上侧边栏的体验明显更好。如果你从来不看 Twitch，这款软件和你没关系。

怎么装？需要科学上网吗？

Twire 的官方下载渠道有两个：F-Droid 仓库和 GitLab Releases 页面，直接拿 APK 装就行。安装本身不复杂，但有一个现实问题：Twitch 服务在国内是无法直接访问的，所以使用 Twire 观看 Twitch 直播和视频同样需要网络代理。这不是 Twire 本身的限制，是 Twitch 服务的网络环境决定的。只要你的代理能让官方客户端正常使用，Twire 就能用——两者走的是同一套 API。

登录 Twitch 账号后能同步订阅吗？

可以。Twire 支持 Twitch 账号登录，登录后订阅列表、关注的频道都会同步到客户端里。已登录用户可以在底部导航栏切换订阅流和热门推荐流——切换不需要重载界面，频道卡片即时刷新。未登录用户只能看到推荐流和分类浏览，订阅流区域灰显。需要注意的是，Twire 不支持 Twitch Prime 相关功能，也不能在客户端内购买 bits 或订阅主播的付费频道——这些互动功能还是得回到官方客户端或网页端。

后台播放和锁屏播放是怎么实现的？

这是 Twire 比较好用的特性之一。进入后台后会自动注册 Android 前台服务——Twire文档里专门有章节解释了前台服务的实现原理，以及国产 ROM 被杀进程时怎么加白名单。通知栏常驻一个播放控件——可以暂停/播放、切上一个或下一个频道、直接关闭，锁屏状态下拉通知栏就能操作，不需要解锁。锁屏播放分两种：纯音频模式完全关掉屏幕、零视频渲染、最省电；画中画模式在锁屏上维持一个小窗口显示视频。不过国产 ROM 对后台进程管理比较激进，小米、OPPO、vivo、华为这些系统里，即使开了前台服务，锁屏一段时间后仍可能被系统杀掉。解决办法是在系统设置里把 Twire 加入电池优化白名单，或者在自启动管理里允许它后台运行。

导航布局有什么可以调的？

Twire 给了用户比较大的自由度。底部标签式和侧边抽屉式两种布局可以随时切换，小屏手机默认底部标签，大屏设备默认侧边抽屉——你手动选过之后就会覆盖自动适配，保持你的选择。除了位置，还能自定义显示哪些入口、调整顺序——比如只保留订阅流和分类浏览，把热门推荐藏起来。官方客户端在这点上比较死板，只能用底部标签，没得选。侧边抽屉的优势是不占主界面空间，单手双手操作都顺手，代价是需要多一个滑出动作。

有什么已知的限制或坑？

几个点提前说清楚。第一，Twitch 的 API 偶尔会限流，Twire 拉数据时可能出现频道列表刷新慢或加载失败，一般等几分钟就恢复，不是客户端本身的 bug。第二，部分国产 ROM 的画中画功能在锁屏后会自动消失，只剩音频继续播——这是系统对 PiP 的限制，不是 Twire 能控制的。第三，Twire 目前没有 VOD 下载功能，只能在线看。第四，登录 Twitch 账号时需要在系统浏览器里完成 OAuth 授权，授权完成后自动跳回 Twire——这一步必须在有代理的环境下才能走通。

最后一句：如果你经常看 Twitch 又受不了官方客户端的广告和臃肿，Twire 值得装一个试试。

资料同步在 GitHub、Gitee 和 GitCode 三处，国内访问哪家顺手就用哪家。
