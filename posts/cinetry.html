Cinetry 实战：五分钟把家里所有媒体源装进同一个播放器

网页版 2026-10-16 ·约 7 分钟 ·老杨

还在 Emby、IPTV、网盘之间来回切换？这篇教程带你从零搭建 Cinetry 多源聚合，一套客户端搞定所有媒体。

看完这篇，你能在 Cinetry官网 里同时接入 Emby、Jellyfin、IPTV 直播源、网盘甚至音乐服务器，实现一键跨库搜索和无缝切换播放——手机、平板、电视、电脑四套设备统一一套配置。

准备：你需要什么

平台：Cinetry 六平台覆盖——Android、iOS、Windows、macOS、Linux、安卓电视。这篇以 Windows 桌面版 + Android 手机端为例，操作逻辑全平台一致。

前置条件（按需准备，没有的可以跳过对应步骤）：

  • 一台 Jellyfin 或 Emby 媒体服务器的地址和 API Key（内网或公网均可）
  • 一份 IPTV m3u / m3u8 直播源地址或本地文件
  • 可选：Webdav 网盘地址、Subsonic 音乐服务器、夸克网盘账号

不用一次把所有源都准备好——先接一个跑通，后面随时加。

第一步：下载安装 Cinetry

Cinetry 的安装包从官方下载拿。桌面版是绿色解压包，解压到任意目录双击 exe 就能跑；Android 端下载 apk 安装即可，iOS 侧需要通过 TestFlight 分发。

装完打开，首页会先引导你添加第一个资源库。界面默认暗色主题，左侧是全局导航（点播 / 直播 / 音乐 / 设置），右侧是当前选中资源库的内容区。

第二步：添加你的第一个媒体服务器

推荐先从 Jellyfin 或 Emby 开始——这是 Cinetry 最核心的两种资源库类型。

操作路径：左侧导航点「设置」→「资源库管理」→ 右上角「+ 添加资源库」→ 选择 Jellyfin 或 Emby。

填写参数：

字段填什么
显示名称随便起，比如「家里Jellyfin」
服务器地址内网填 http://192.168.x.x:8096，公网填你的域名
API Key去 Jellyfin 后台 → 高级 → API Keys 里新建一个

填完点「测试连接」，绿灯亮了就保存。Cinetry 会自动拉取服务器上的分类、推荐内容、观看进度——第一次同步可能要等几十秒，库越大越慢。

第三步：导入 IPTV 直播源

IPTV 是 Cinetry 的另一大主力资源类型——和 Jellyfin 不同，IPTV 走的是 m3u/m3u8/txt 格式的直播点播源，不需要账号密码。

操作路径：「设置」→「资源库管理」→「+ 添加资源库」→ 选择 IPTV。

两种导入方式：

  • URL 导入：把 m3u 或 TvBox txt 的链接直接粘进去，Cinetry 会实时拉取
  • 本地文件导入：如果你下载了 .m3u 文件，选这个方式从本地读取

导入成功后左侧导航会多出「直播」Tab，里面按 IPTV 源自动分好频道组。点播首页也会出现 IPTV 源里的点播分类。

第四步：给每个资源库设好功能开关

这一步很多新手会跳过，结果就是首页内容乱糟糟、搜索结果被无关内容污染。Cinetry 给每个资源库提供了三个独立开关，控制它的参与范围：

开关作用推荐设置
首页开关内容是否出现在点播首页主力库开，分享库关
搜索开关是否参与全局搜索大部分开，测试/文件库关
成人开关标记是否含成人内容IPTV 源按需开

举个实际场景：你同时接了自家 Jellyfin、朋友分享的 Emby、两份 IPTV。

  • 自家 Jellyfin：首页开 + 搜索开（主力）
  • 朋友 Emby：首页关 + 搜索开（只想搜索时用，不占首页位置）
  • IPTV 源 A：首页开 + 搜索开 + 成人开（内容比较全）
  • IPTV 源 B：首页关 + 搜索开（备选，不常看）

从 0.7.11 版本起支持批量编辑——选中多个资源库一次性改开关，手里库多时省不少事。

第五步：多服务器之间一键切换

当你接了三个以上资源库后，Cinetry 顶部会出现服务器切换器——显示当前正在浏览的服务器名称，点一下展开完整列表。

切换后哪些东西会变、哪些不变：

  • 首页内容 → 变成目标服务器的分类和推荐
  • 侧边栏导航 → 全局不变
  • 正在播放的视频 → 不受影响继续放
  • 播放进度 → 各自同步到对应服务器

切换列表里每个服务器旁边有实时连接状态——绿色在线、灰色离线。某个服务器挂了你一眼就能看出来，不会点进去才发现。

保存配置是自动的：添加过的服务器地址和 API Key 会加密存在本地，下次切换直接调，不用重新填。服务器切换的更多场景组合和连接状态排查，Cinetry文档里写得比我细多了。

常见卡点：三个新手最容易翻车的地方

卡点一：IPTV 导入后频道为空

八成是源地址挂了。排查三步走：

  1. 把 m3u 地址复制到浏览器里打开——能不能下载到文件？下载后打开是不是以 #EXTM3U 开头？
  2. 某些源有 IP 白名单或限运营商——换手机流量 / Wi-Fi 试试，或者用 VPN 切不同节点
  3. 拿不到 URL 就把 m3u 下载到本地，用本地文件导入绕过网络问题

免费 IPTV 源本来就是不稳定的，个别频道失效是常态。常备 2~3 份不同的源，一个不行换另一个。

卡点二：Emby/Jellyfin 连接测试失败

  • API Key 填错：Jellyfin 后台 → 高级 → API Keys 里新建，注意别复制到空格
  • 内网地址外网访问：家里的 192.168.x.x 地址在外网连不上，需要做端口映射或用 Frp/Tailscale 之类的内网穿透
  • 防火墙挡住了：服务器端 8096（Jellyfin）或 8096/8920（Emby）端口要放行

卡点三：首页内容太杂太多

回到第四步，给资源库设好功能开关。主力库开首页，其他分享库、测试库统统关首页只开搜索——这样首页干净，搜索时又能跨所有库搜。

进阶一句话

跑通视频之后试试把 Subsonic 或 Navidrom 音乐服务器也接进来，Cinetry 左侧会多出「音乐」Tab，一套 App 管视频管音频管有声书。这套关于 Cinetry 的资料在 GitHub、Gitee、GitCode 三处都有备份，国内访问不了 GitHub 的时候直接切 Gitee 或 GitCode 就行。
